# سامانه مدرسه - Android APK

این پروژه یک برنامه Android مبتنی بر WebView برای سامانه زیر است:

https://www.zaminsports.lol/hazer/school_attendance_system/

## قابلیت‌ها
- باز شدن سامانه داخل برنامه Android
- حفظ کوکی و ورود کاربران
- آپلود فایل برای Excel/PDF/Word و دستیار هوشمند
- دانلود فایل‌های PDF، Excel، Word و تصویر
- دکمه Back گوشی برای برگشت داخل سامانه
- پشتیبانی از لینک‌های خارجی

## ساخت APK با GitHub Actions
با Push روی شاخه main، Workflow با نام Build Android APK اجرا می‌شود.
پس از اتمام، Artifact با نام SchoolAttendance-APK شامل app-debug.apk خواهد بود.
